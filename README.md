# DTZ B1 · Письмо

Курс немецкого для письменной части экзамена **Deutsch-Test für Zuwanderer
(DTZ)** уровня B1. Для русскоговорящих, которые пишут письма с грамматическими
ошибками: курс начинает с самых частых ошибок, а не с самых редких, и
проверяет письмо сразу.

Работает офлайн, ставится на главный экран телефона как приложение.

## Что внутри

- **Входной тест** на 44 вопроса: показывает слабые темы и расставляет модули
  по порядку.
- **Одиннадцать модулей грамматики**: порядок слов, придаточные, глаголы,
  прошедшее время, модальные глаголы и вежливость, существительные и артикли,
  падежи, прилагательные, предлоги, связность, орфография. В каждом короткая
  теория с ловушками для русскоговорящих, около сорока упражнений семи видов
  и мини-письмо.
- **Техника письма**: структура и регистр, как превратить четыре пункта
  задания в предложения.
- **Двенадцать ситуаций, двадцать четыре задания в стиле DTZ**: образец
  уровня B1, слабый ответ с разбором, опорные фразы и упражнения.
- **Окно письма**: проверка на типичные ошибки (порядок слов, запятые, Perfekt,
  обращение и прощание), самооценка по четырём критериям экзамена, запрос на
  проверку для Claude.
- **Проба экзамена (Schreiben)**: 30 минут, два задания на выбор, без подсказок.
- **Lesen (чтение)**: пять частей экзамена — таблички и списки, объявления,
  короткие сообщения, длинные инструкции, письмо с пропусками. У каждой части
  стратегия, упражнения на навык и шесть наборов заданий; шесть вариантов пробы
  на 45 минут (25 заданий) и разбор с подсветкой места в тексте.
- **Шпаргалка** для быстрого освежения: схемы порядка слов, союзы,
  конструкции с переводами, таблицы форм; с поиском.
- **Повторение** по ящикам: ошибка возвращается скоро, верный ответ — реже.
- **Клиника ошибок**, **фразы для письма** с карточками, **страница об
  экзамене**.

Полное описание — [docs/SPEC.md](docs/SPEC.md). Что и почему решали —
[docs/DECISIONS.md](docs/DECISIONS.md). Как писать содержимое —
[docs/CONTENT.md](docs/CONTENT.md).

## Запуск

Курс — набор статических файлов, сборка не нужна. Но модули ES и
сервис-воркер не работают через `file://`, поэтому нужен любой локальный
сервер:

```bash
powershell -ExecutionPolicy Bypass -File tools/serve.ps1
```

Затем открыть `http://localhost:4190`. Порт меняется ключом `-Port`.

## Проверки

Открыть `/tests/index.html` на том же локальном сервере. Проверки идут в
браузере; зелёная полоса сверху и галочка в заголовке вкладки означают, что
всё прошло. Работают они на отдельном ключе хранения `briefe.test` — ваш
прогресс при запуске не трогается.

Те же проверки и два дополнительных прогона из консоли (нужен Node и
Playwright):

```bash
node tools/ci-tests.mjs http://localhost:4190/tests/index.html   # то же, что на странице
node tools/e2e.mjs http://localhost:4190/                        # курс по экранам, каждое упражнение
node tools/validate-content.mjs                                  # структура и ключи содержимого
node tools/corpus-check.mjs                                      # проверка писем на всех верных предложениях
```

На каждый push и pull request те же проверки прогоняет GitHub Actions.

## Разработка

```text
index.html           разметка оболочки, без стилей и скриптов
css/style.css        все стили, цвета переменными в :root
sw.js                кэш и офлайн; список файлов пишет tools/make-sw.mjs
manifest.json        описание PWA

js/main.js           точка входа
js/app.js            маршрутизация (#/drill/g01)
js/version.js        версия и название курса

js/core/check.js     сверка ответов: предложения, пропуски, плашки
js/core/exercise.js  карточка упражнения и проверка по семи типам
js/core/session.js   занятие: очередь, ответы, итог
js/core/sources.js   откуда берутся упражнения (модуль, повтор, тема)
js/core/store.js     прогресс в localStorage, ящики повторения
js/core/progress.js  сводка: модули, письма, следующий шаг
js/core/brief.js     проверка писем на типичные ошибки
js/core/markup.js    **жирное** и `немецкое` внутри строк содержимого
js/core/actions.js   делегирование событий по data-action
js/core/ui.js        сборка разметки с экранированием

js/modules/          экраны: home, module, drill, letters, tools
js/data/             содержимое курса (см. docs/CONTENT.md)
js/data/index.js     ГЕНЕРИРУЕТСЯ: tools/make-index.mjs

docs/                описание проекта, журнал решений, как писать содержимое
tests/               проверки, запускаются в браузере
tools/               сервер, проверки содержимого, сквозной прогон, значки
```

Правила, которые важно не нарушить:

- ответ «верно или нет» решает `js/core/check.js` и больше никто: ни один
  экран не сверяет строки сам;
- любое значение, попадающее в разметку, проходит через `ui.esc()` или
  шаблон `ui.html`;
- обработчики вешаются через `data-action`, а не `onclick`;
- цвета берутся из CSS-переменных, а не задаются в JavaScript;
- после нового файла содержимого: `node tools/make-index.mjs`, затем
  `node tools/make-sw.mjs` и подъём `APP_VERSION` в `sw.js`;
- содержимое перед выкладкой проходит `node tools/validate-content.mjs` и
  глазами: машина не читает по-немецки.
