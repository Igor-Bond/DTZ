# Как писать содержимое курса

Этот файл — для тех, кто пишет уроки, упражнения и письма (человек или
помощник). Всё содержимое лежит в `js/data/` обычными модулями ES, без
сборки, и проверяется командой:

```bash
node tools/validate-content.mjs                      # всё
node tools/validate-content.mjs js/data/grammar/g01-satz.js   # один файл
```

Код ничего не знает про отдельные уроки: добавили файл, внесли его в
`js/data/index.js` — и он появился в приложении, в печатном учебнике и в
повторении.

## Для кого и зачем

Читатель — русскоговорящий взрослый, который готовится к **письменной части
Deutsch-Test für Zuwanderer (DTZ) уровня B1** и делает много грамматических
ошибок, когда пишет сам. Цель курса — не «знать грамматику», а писать
письма без ошибок, которые стоят баллов.

### Что известно про экзамен (проверено по официальному руководству BAMF/Goethe и образцам telc)

- Письменная часть «Schreiben» — **одно задание, 30 минут**. Два варианта на
  выбор (Aufgabe A или B), надо выбрать один.
- Задание — короткое письмо или сообщение: вводный текст описывает ситуацию
  (вы пишете учительнице, соседу, хозяину квартиры…), затем **четыре
  пункта (Leitpunkte)**, которые надо раскрыть. Обязательны **обращение
  (Anrede) и прощание (Gruß)**. Формулировка: «Zeigen Sie, was Sie können:
  Schreiben Sie möglichst viel.»
- Словарей нет. Пишут от руки прямо на листе ответа. Оценивается только то,
  что на листе.
- Регистр — полуформальный или формальный (Sie), иногда дружеский (du).
- Оценивают двое, по четырём критериям, **каждый от 0 до 5, итого 20**:
  I Aufgabenbewältigung (пункты задания), II Kommunikative Gestaltung
  (связность, обращение и прощание, уместный регистр), III Korrektheit
  (грамматика и орфография), IV Wortschatz. B1 — от 15 баллов (75 %),
  A2 — от 7. Результат — уровень B1, A2 или ниже A2.
- Образцы из руководства: B1-письмо на 77 слов, с заметными грамматическими
  ошибками, всё равно получило B1: ошибки не мешали понять смысл, а все
  пункты были раскрыты и связаны. Поэтому курс учит **сначала раскрыть
  пункты и связать текст, потом убирать ошибки** — и ошибки отсекает по
  частоте, а не по редкости.

Не придумывайте формулировок «по официальным данным», которых здесь нет.

## Общие правила для любого текста

1. **Немецкий — безупречный.** Каждая форма глагола, род, падеж и окончание
   проверены. Если не уверены в правиле — не включайте его. Курс, который
   учит ошибке, хуже, чем отсутствие курса. Двусмысленные упражнения, где
   верны два ответа, а засчитан один, запрещены.
2. **Уровень A2–B1.** Лексика бытовая и из писем: курс, термин, квартира,
   врач, договор, жалоба. Никакого Passiv, Konjunktiv I, Genitiv-конструкций
   (кроме «wegen» и самого необходимого), редких слов.
3. **Объяснения — на русском**, коротко и по делу, на «вы»: «Глагол стоит на
   втором месте», а не «Мы с вами увидим, что…». Один абзац — одна мысль.
4. **Опора на родной язык.** Где русский порядок слов, артикль (его нет в
   русском), род, падеж или предлог мешает — скажите это прямо, в `trap`.
5. **Примеры — из жизни письма.** Не «Der Hund frisst die Wurst», а «Meine
   Tochter ist krank», «Ich möchte den Termin verschieben».
6. Не копируйте тексты экзаменов и учебников. Ситуации и фразы придумываются
   свои, в духе DTZ.
7. Никаких личных данных, настоящих адресов и телефонов.

## Разметка внутри строк

Только две:

- `**жирное**` — выделение (в примерах: то, на что смотреть, например
  глагол);
- обратные кавычки — немецкий фрагмент внутри русского текста:
  `` `Ich komme morgen.` ``.

Остальное — обычный текст. Угловые скобки и амперсанд писать можно, они
экранируются. Строки в одну строку, без переносов.

## Темы ошибок (`tag`)

Каждое упражнение помечено ровно одной темой из `js/data/tags.js`. Словарь
закрытый. Выбирайте ту, из-за которой читатель ошибся бы.

## Модуль грамматики (`js/data/grammar/gNN-имя.js`)

```js
export default {
    id: 'g01',                 // gNN — как в имени файла
    order: 1,
    title: 'Порядок слов: глагол на втором месте',
    short: 'Порядок слов',     // для плитки на главной, до 24 знаков
    goal: 'После модуля вы …', // что вы будете уметь, одно предложение
    why: 'Почему это важно именно для письма на DTZ …', // 2–3 предложения
    theory: [ ...блоки... ],   // 25–45 блоков
    exercises: [ ...задания... ],  // 36–48 заданий
    apply: { ... }             // мини-письмо с самопроверкой
};
```

### Блоки теории

| Блок | Поля | Для чего |
|---|---|---|
| `{ type: 'h', text }` | подзаголовок | делит теорию на шаги, нумеруйте: «1. …» |
| `{ type: 'p', text }` | абзац | пояснение, 1–3 предложения |
| `{ type: 'rule', text }` | правило | то, что надо запомнить, одна-две строки |
| `{ type: 'list', items: [..] }` | список | перечисления |
| `{ type: 'table', head: [..], rows: [[..]], note? }` | таблица | формы, позиции, окончания; `note` — подпись |
| `{ type: 'ex', de, ru }` | пример | `de` с `**выделением**`, `ru` — перевод |
| `{ type: 'exs', items: [{ de, ru }] }` | группа примеров | 3–6 примеров подряд |
| `{ type: 'trap', wrong, right, why }` | ловушка | типичная ошибка русскоговорящего: неверное, верное, почему |
| `{ type: 'tip', text }` | совет | как применить на экзамене |

Ритм хорошего модуля: короткое правило → таблица → 3–5 примеров из писем →
ловушки → совет. Не больше двух абзацев подряд без примера. Теория
читается за 8–12 минут.

### Упражнения

Общие поля: `id` (`g01-07`: модуль-номер, уникален во всём курсе), `type`,
`q` (задание по-русски, до 140 знаков), `explain` (почему именно так, 1–3
предложения, обязателен всегда, показывается и при верном ответе, и при
неверном), `tag` (тема ошибки), `diag: true` (только у 4 заданий модуля —
они войдут в входной тест; выбирайте самые показательные).

Соотношение в модуле примерно: `choice` 25 %, `gap` 30 %, `build` 15 %,
`fix` 15 %, `join`/`translate`/`order` 15 %. Лёгкие в начале, труднее к
концу.

**`choice`** — выбор из 2–4 вариантов. Порядок перемешивается приложением,
поэтому не ссылайтесь на «вариант а» в `explain`.

```js
{ id: 'g01-01', type: 'choice', q: 'Какое предложение правильное?',
  options: ['Heute ich komme später.', 'Heute komme ich später.', 'Ich heute komme später.'],
  answer: 1, explain: '…', tag: 'verb2', diag: true }
```

Необязательное поле `text` — контекст над вопросом (например, начало
письма). Правильный вариант один: остальные неверны по причине, которую вы
можете назвать.

**`gap`** — пропуск(и) в предложении, ответ вводится с клавиатуры. Каждый
пропуск записывается как `___`, ответов столько же.

```js
{ id: 'g01-12', type: 'gap', q: 'Вставьте глагол.',
  text: 'Heute ___ ich leider nicht kommen.', hint: 'können',
  answer: ['kann'], explain: '…', tag: 'verb2' }
```

`answer` — массив: по элементу на пропуск; элемент — строка или массив
допустимых вариантов (`[['rufe'], ['an']]`, `[['dem', 'einem']]`). `hint` —
подсказка в скобках (инфинитив, перевод, часть речи). Перечислите **все**
верные варианты (в том числе сокращения: `zum` или `zu dem`). Регистр
учитывается, кроме начала предложения. Не делайте пропуск, где верны два
слова разного смысла, если в тексте нет подсказки, которая оставляет одно.

**`build`** — составить предложение из слов (плашки). Основа — немецкое
предложение, разрезанное по словам; знаки препинания приклеены к слову
(`'nicht,'`, `'bin.'`).

```js
{ id: 'g01-20', type: 'build', q: 'Составьте предложение.',
  ru: 'К сожалению, я не могу прийти сегодня.',
  answer: ['Leider kann ich heute nicht kommen.', 'Heute kann ich leider nicht kommen.'],
  explain: '…', tag: 'verb2' }
```

`answer` — все допустимые порядки; плашки берутся из первого, регистр при
сверке не учитывается, поэтому в разных вариантах набор слов одинаков с
точностью до регистра и порядка. Запятая — часть слова-плашки, её тоже
видно. Не более 12 слов. Необязательно: `words` — явный набор плашек (если
хотите добавить лишнее слово-ловушку, то оно в `answer` не входит и
называется `extra: ['den']`).

**`fix`** — найти ошибку и переписать предложение. Ответ вводится целиком.

```js
{ id: 'g01-28', type: 'fix', q: 'Исправьте ошибку.',
  text: 'Heute ich bin krank.', answer: ['Heute bin ich krank.'],
  explain: '…', tag: 'verb2' }
```

В предложении **ровно одна** ошибка, та, что объясняется в теме. Перечислите
все естественные исправления. Читатель, чей вариант не совпал, может
засчитать его сам — но чем полнее список, тем меньше таких случаев.

**`join`** — соединить два предложения заданным союзом.

```js
{ id: 'g02-14', type: 'join', q: 'Соедините союзом weil.',
  parts: ['Ich komme nicht.', 'Ich bin krank.'], connector: 'weil',
  answer: ['Ich komme nicht, weil ich krank bin.', 'Weil ich krank bin, komme ich nicht.'],
  explain: '…', tag: 'nebensatz' }
```

**`translate`** — перевод с русского, ответ вводится целиком. Используйте
редко и только там, где вариантов немного: в `answer` минимум 3 варианта.

```js
{ id: 'g01-38', type: 'translate', q: 'Переведите.',
  ru: 'Сегодня мы, к сожалению, не можем прийти.',
  answer: ['Heute können wir leider nicht kommen.', 'Leider können wir heute nicht kommen.', 'Wir können heute leider nicht kommen.'],
  explain: '…', tag: 'verb2' }
```

**`order`** — расставить части по порядку (абзацы письма, этапы). `items` —
в **правильном** порядке, приложение перемешает.

```js
{ id: 'l01-05', type: 'order', q: 'Расставьте части письма по порядку.',
  items: ['Sehr geehrte Frau Meinert,', 'ich schreibe Ihnen, weil …', '…', 'Mit freundlichen Grüßen'],
  explain: '…', tag: 'aufbau' }
```

### Как проверяются ответы (знайте, чтобы не ошибиться в списках)

Из введённого берётся текст, лишние пробелы схлопываются. `ä ö ü ß` можно
писать как `ae oe ue ss` — засчитывается с пометкой. У `gap`, `fix`,
`join`, `translate` сравниваются слова с учётом регистра (кроме первого слова
предложения), а затем отдельно знаки препинания: если слова верны, а запятая
нет, ответ засчитывается с замечанием «проверьте запятые». Поэтому в
вариантах `answer` запятые ставятся строго по правилам.

### Мини-письмо `apply`

```js
apply: {
    task: 'Напишите 4–5 предложений …',   // задание по-русски
    checks: [ 'Во всех предложениях глагол на втором месте', '…' ],  // 3–5 пунктов самопроверки
    model: 'Sehr geehrte Frau Meinert, …', // образец, 40–70 слов
    modelRu: '…'                           // перевод образца
}
```

Образец строго проходит все пункты `checks`.

## Письмо (ситуация) `js/data/letters/sNN-имя.js`

Ситуация — типовой повод для письма (извинение за пропуск, жалоба,
расторжение договора…). В ней два задания в стиле DTZ.

```js
export default {
    id: 's01',
    order: 1,
    title: 'Извинение: пропуск курса или школы',
    short: 'Пропуск курса',
    register: 'halbformell',   // 'formell' | 'halbformell' | 'informell'
    intro: 'Что обычно просят …, кому пишут, какой тон …',   // 2–3 предложения
    phrases: [ { de: 'Ich schreibe Ihnen, weil …', ru: 'Я пишу вам, потому что …', use: 'Einleitung' } ],  // 10–16 опорных фраз
    tasks: [ { ...задание A... }, { ...задание B... } ],
    drills: [ ...упражнения как в грамматике (6–10 штук), id вида s01-d1... ]
}
```

Поле `use` у фразы — одна из: `Anrede`, `Einleitung`, `Grund`, `Entschuldigung`,
`Bitte`, `Frage`, `Information`, `Vorschlag`, `Termin`, `Zusage`, `Absage`,
`Beschwerde`, `Dank`, `Schluss`, `Gruß`.

### Задание

```js
{
    id: 's01-a',
    label: 'A',
    situation: 'Sie besuchen einen Deutschkurs. Sie können diese Woche nicht in den Kurs kommen. Deshalb schreiben Sie an Ihre Lehrerin, Frau Meinert.',
    recipient: 'Frau Meinert',
    register: 'halbformell',
    points: [
        { de: 'Grund für Ihr Schreiben', hint: 'Скажите, что вы пишете о пропуске.',
          starters: ['Ich schreibe Ihnen, weil …'],
          keys: ['schreib', 'weil', 'Kurs'] },
        { de: 'Entschuldigung', hint: '…', starters: ['Es tut mir leid, dass …'], keys: ['Entschuldig', 'leid'] },
        { de: 'Hausaufgaben', hint: '…', starters: ['…'], keys: ['Hausaufgabe'] },
        { de: 'Rückkehr in den Kurs', hint: '…', starters: ['…'], keys: ['wieder', 'nächste Woche', 'komme'] }
    ],
    model: {
        text: 'Sehr geehrte Frau Meinert, …',   // 70–100 слов, B1, см. ниже
        ru: 'Перевод образца.',
        notes: ['Пункт 1 раскрыт в первом предложении: …', '…']  // 4–6 заметок «почему это B1»
    },
    weak: {   // необязательно, но очень желательно для задания A
        text: 'Hallo Frau Meinert. Ich nicht kommen …',   // слабый ответ уровня A2 с типичными ошибками
        fixes: [ { was: 'Ich nicht kommen', wird: 'Ich kann nicht kommen', why: 'Модальный глагол …' } ]
    }
}
```

- Текст `situation` — на немецком, 2–3 коротких предложения, как в экзамене;
  последним предложением идёт адресат. Пункты `points` — ровно **четыре**,
  в формулировке экзамена (`de`): «Grund für Ihr Schreiben», «Entschuldigung»,
  «Bitte um …», «Terminvorschlag». Это короткие словосочетания.
- `hint` — что именно сказать, по-русски, одним предложением.
- `starters` — 1–2 начала фразы на немецком, которые помогают начать.
- `keys` — 2–6 корней слов (без окончаний, регистр не важен), по которым
  приложение предполагает, что пункт раскрыт. Выбирайте слова, которые
  почти наверняка встретятся при любом правильном ответе.
- `model.text` — образец **уровня B1, не выше**: 70–100 слов, все четыре
  пункта раскрыты по порядку или логично связаны, **Anrede и Gruß есть**, 4–6
  придаточных или связок (weil, dass, wenn, deshalb, außerdem …), хотя бы
  одно Perfekt и одна вежливая форма (könnten Sie…, ich würde gern…). Без
  ошибок вообще. Прогоняется через проверку писем, которая обязана ничего не
  найти.
- `weak.text` — ответ слабее, 40–60 слов, с 5–8 типичными ошибками
  русскоговорящего; `fixes` — разбор каждой ошибки.
- `notes` — по 1 предложению: что именно в образце делает его B1
  («Связка `deshalb` и инверсия показывают умение строить сложные
  предложения»).

Нельзя копировать задания из официальных образцов. Придумайте свои.

## Клиника ошибок `js/data/errors.js`

Каталог типовых ошибок русскоговорящих в письме. Файл экспортирует
массив семейств:

```js
export default [
    { id: 'f1', title: 'Порядок слов', items: [
        { id: 'f1-01', title: 'Heute ich bin …',
          wrong: 'Heute ich bin krank.', right: 'Heute bin ich krank.',
          rule: 'Глагол всегда на втором месте …',
          why: 'В русском «Сегодня я болен» …',
          tag: 'verb2',
          drills: [ { упражнения fix/choice/gap, id вида f1-01-a } ] }
    ]}
];
```

В каждой записи 1–2 упражнения. `tag` — тема ошибки, по которой читатель
пойдёт в модуль.

## Фразы `js/data/phrases.js`

```js
export default [
    { id: 'p01', title: 'Обращение и прощание', items: [
        { de: 'Sehr geehrte Frau …,', ru: 'Уважаемая госпожа …,', note: 'формально; запятая после обращения' }
    ]}
];
```

`note` необязателен. Фразы — готовые заготовки для письма, которые
вставляют целиком. Фраза с пропуском пишется через `…`.

## Справочник `js/data/reference.js` и шпаргалка `js/data/cheatsheet.js`

Оба файла экспортируют массив разделов `{ id, title, drill?, blocks: [..блоки теории..] }`.
Это шпаргалки, которые читатель открывает во время работы и перед
экзаменом, чтобы быстро освежить в памяти. `reference.js` — таблицы форм
(спряжение, склонение, предлоги); `cheatsheet.js` — схемы порядка слов, союзы
и конструкции с переводами. Читаются за минуты, а не часы: минимум слов,
максимум примеров и переводов.

Необязательное поле раздела `drill` — ключ источника упражнений, который
откроется кнопкой «Проверить себя»: id модуля (`'g02'`) или тема ошибки
(`'тема:verb2'`).

Дополнительный блок для шпаргалок — формула: цветные плашки в одну строку,
наглядная схема предложения.

```js
{ type: 'formula', parts: ['1-е место', '**глагол**', 'подлежащее', 'остальное', '**2-я часть глагола**'],
  note: 'Рамка: две части глагола окружают середину.' }
```

`parts` — от 2 до 8 коротких частей (разметка `**` допустима), `note` — подпись.

## Чек-лист перед сдачей файла

- `node tools/validate-content.mjs <файл>` не выдаёт ошибок (предупреждения
  разобрать — часть можно оставить, но каждое надо понять);
